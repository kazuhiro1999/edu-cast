# 全体方針サマリ

作成日: 2026-10-23。詳細と出典は各章。

## 一言で
**「情報系の学び」1ニッチ × 自作 VRM キャラ × Ink 台本をエンジン再生して録画**。応用情報→2027年新試験の体系を背骨にし、時事と AI 用語を接ぎ木する。Shorts は獲得装置と割り切り、収益は長尺・物販・パイプライン自体の B2B 化で取る。

## 重要な前提と未確認事項

1. **Irodori-TTS の重みの商用可否**が未確認。NG なら LoRA 自作声か VOICEVOX 系へ。TTS 段はアダプタで抽象化しておく。
2. 「2027 に新しく出る IPS」は IPA 新試験制度と解釈した。別物なら ① の前提が変わる。
3. YouTube の数値（RPM、セーフゾーン、ハッシュタグ上限）は公式データが無いものが多く、第三者推計。自チャンネルの Analytics で上書きする前提。
4. 2026-07 の YouTube 明確化で「AI ペルソナが健康・金融・法律を語る動画」は収益化不可。IT 教育は安全圏だが、財務・法務ユニットは試験知識の説明にとどめる。
5. 調査環境ではページ本文の直接取得が一部ブロックされ、検索スニペット由来の数値がある。各章の出典で一次情報を再確認すること。
